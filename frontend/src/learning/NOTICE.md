# Learning word pack attribution

Hard-word levels are derived from:

- **CEFR-J Vocabulary Profile (ver 1.5)**  
  Compiled by Yukio Tono, Tokyo University of Foreign Studies.  
  Packaged via [openlanguageprofiles/olp-en-cefrj](https://github.com/openlanguageprofiles/olp-en-cefrj).  
  Usable for research and commercial purposes with proper citation.

Short Chinese glosses for matching lemmas are abbreviated from public ECDICT-style
dictionary fields for on-device lookup only (no network request at runtime).

This pack is used solely for **local, algorithmic** learning glosses. It is not
the Cambridge English Vocabulary Profile and is not used for AI translation.
