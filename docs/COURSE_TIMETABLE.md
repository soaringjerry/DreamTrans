# 课表与会话自动归类

学习空间里的每门课程可以设置每周固定的上课时间（周几、开始、结束、时区，
可选备注）。设置之后，系统按时间重叠把转录会话归到对应课程，不调用模型，
不产生费用。

## 归类规则

- 每个时段是所在时区里的一个每周墙钟窗口；会话的开始时间先换算到该时区，
  再决定它落在周几、哪一天。
- **已知时长**（会话结束后）：会话与时段有重叠，且重叠覆盖了会话的一半或
  课程的一半以上，即视为匹配。连堂课之间按重叠更长的那门归属；课上录的一
  段短测试也算这门课。
- **时长未知**（会话刚创建）：开始时间落在课前 20 分钟到课程结束前 10 分钟
  之间即匹配，多个时段同时匹配时取开始时间最近的。
- 课程设置了「第 1 周的周一」时，早于该日期的会话不会归到这门课，避免同一
  门课跨学期复用时吞掉上学期的录音。

## 什么时候归类

| 时机 | 依据 | 行为 |
|---|---|---|
| 创建云端会话 | 开始时间 | 立即归类，响应里带 `project_id` |
| 会话标记为已完成 | 实际时长 | 重新匹配；只会移动由课表归类的会话 |
| 课程列表页「自动归类会话」 | 全部历史会话（最多 2000 场） | 先预览，再一键应用 |

手动挂进课程的会话（`assigned_by = manual`）永远不会被课表移动。课表归类的
会话在课程会话列表里带「课表」标记；用户手动移动一次之后就变成手动链接。
删除一个时段不会把已归类的会话移出课程。

## 接口

```
GET    /api/ai/projects/{id}/timetable            列出课程时段
POST   /api/ai/projects/{id}/timetable            {weekday, start, end, timezone, label}
DELETE /api/ai/projects/{id}/timetable/{slot_id}
GET    /api/ai/timetable                          用户全部课程的时段（含课程名）
POST   /api/ai/timetable/classify                 {apply: bool} 预览或应用归类
```

`weekday` 为 ISO 星期（1 = 周一 … 7 = 周日），`start`/`end` 为 `HH:MM`，
`timezone` 为 IANA 时区名。每门课最多 20 个时段。

## 数据

迁移 `042_course_timetable.sql` 新增 `course_slots` 表，并给 `project_sessions`
加上 `assigned_by`（`manual` / `timetable`）与 `slot_id`。旧的会话链接全部视为
手动链接。时区数据随二进制内嵌（`time/tzdata`），运行镜像不需要额外安装。
