# 学习空间的课程资料更新

资料提取完成后，需要由用户确认并重新生成技能路线。上传、提取状态轮询和
原文检索不会自动触发付费模型或语义索引。页面会提示资料仍在提取、路线过期，
并在生成路线前说明费用。旧版没有资料指纹的路线也需要重新生成一次。

重新生成会依据当前转录和上传资料重建能力、顺序与前置依赖；旧图谱仅供同义
能力名称匹配，不再要求保持旧顺序。后端保留有效的跨顺序依赖，去掉循环、自引用
和不存在的引用，并按依赖重新排序。学习路线按真实依赖分层和连线，不再把相邻
节点一律连成单线。旧版生成时已丢失的依赖需要重新生成才能恢复。
相同能力名继续关联原有等级和 XP；拆分、合并或更名后的能力不会自动继承其他
能力的进度，历史练习记录仍保留。此次结构修复不需要额外数据库迁移。

讲解和题库生成现在除了技能摘要，还通过课程内的免费关键词/相似度检索读取
相关资料原文，优先选择图谱引用的来源。每次最多 8 段、每段 1800 字符，携带
来源名称和段号，并要求模型把资料作为证据而非指令。这不等于把所有文件全文
塞进每一道题；扫描件提取质量和检索相关性仍会影响教学质量。

路线记录生成时的资料指纹。文件新增、删除、重新提取、原文修改以及关联会话
变化后，新教学请求会要求先更新路线。生成期间再次变更资料也不会被标成最新。

迁移 `035_study_content_versions.sql` 为讲解、评分标准和题库增加版本维度。
新版按图谱 artifact ID 读取缓存，计费幂等键也包含新版标识；旧内容保留。
历史题目继续使用自己的评分标准版本，学习等级、XP、练习记录不清空。
运行新后端前必须完成迁移；不要对有业务数据的数据库手工删除旧教学内容。
